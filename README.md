# Restaurant Orders and Menu Performance Analysis

## Project Overview
This project focuses on analyzing restaurant order data to understand food item performance, category-wise sales, revenue generation, and customer ordering patterns.

The project uses Python for data analysis and Excel datasets for storing and managing restaurant order records.

## Objectives
- Analyze restaurant order records.
- Identify the most frequently ordered food items.
- Analyze category-wise orders and revenue.
- Calculate revenue generated by different food items.
- Understand the relationship between quantity and revenue.
- Generate meaningful insights from restaurant data.

## Technologies Used
- Python
- Pandas
- NumPy
- Microsoft Excel

## How to Run the Project

1. Install Python on your computer.
2. Install the required libraries:

```bash
pip install pandas numpy openpyxl
```

3. Download or clone this repository.
4. Open the project folder in VS Code.
5. Run the Python file:

```bash
python restaurant_analysis.py
```
